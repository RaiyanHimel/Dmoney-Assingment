# Project title: Dmoney REST API testing using Postman & Newman
## Project description: This project contains the manual and automated API testing of the Dmoney Payment System.
I tested multiple financial transactions (deposit, send money, withdraw, payment) using Postman, Newman, and manual test case design.
The goal of this project is to practice API testing, documentation, bug reporting, and understanding real-life transaction flows.

### Technology Used:
- Node JS
- Postman
- Newman
- HTML Report Extra

### How to run:
- `npm i`
- node report.js
